## 更新内容

### 1. 过滤标题节点（sec1/sec2/sec3）

在"按标签分组"模式下,树形结构不再显示 sec1/sec2/sec3 等标题节点,只显示实际内容节点。

**修改位置**: `index.vue` - `buildSubTree()` 函数

**实现逻辑**:
```typescript
// 过滤掉 sec1/sec2/sec3 等标题节点
const filteredItems = items.filter(item => {
  const cls = item.class || ''
  return !cls.match(/^sec\d+$/i)
})
```

**效果**:
- 原始数据: 626 个节点 (12 个标题节点 + 614 个内容节点)
- 标签分组模式: 只显示 614 个内容节点
- 原始结构模式: 显示所有 626 个节点 (保持不变)

### 2. 点击标签跳转到内容

点击标签节点(label-group 或 label-group-2)时,自动跳转到该标签下第一个非标签的内容节点。

**修改位置**: `index.vue` - `selectTreeNode()` 函数

**实现逻辑**:
```typescript
// 递归查找第一个非标签节点
const findFirstNonLabelNode = (node: any): any => {
  // 如果当前节点不是标签节点，返回自身
  if (node.class !== 'label-group' && node.class !== 'label-group-2') {
    return node
  }

  // 如果是标签节点，递归查找子节点
  if (node.children && node.children.length > 0) {
    for (const child of node.children) {
      const result = findFirstNonLabelNode(child)
      if (result) return result
    }
  }

  return null
}
```

**用户体验**:
- 点击一级标签 → 跳转到该标签下第一个内容节点的 PDF 位置
- 点击二级标签 → 跳转到该二级标签下第一个内容节点的 PDF 位置
- 点击内容节点 → 直接跳转到该节点的 PDF 位置(原有行为)
