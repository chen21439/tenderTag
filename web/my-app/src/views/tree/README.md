# 论文层级结构可视化

## 功能说明

该模块用于可视化展示论文的层级结构数据（基于 HRDS 数据集格式）。

## 文件结构

```
tree/
├── index.vue          # 主组件：包含左侧树形视图和右侧详情/预览面板
├── TreeNode.vue       # 树节点组件：递归渲染层级结构
├── PaperView.vue      # 纸张预览组件：以论文格式展示内容
├── PaperSection.vue   # 章节组件：处理section的递归渲染
├── BboxView.vue       # Bbox可视化组件：基于坐标还原元素位置
└── README.md          # 本文档
```

## 访问方式

在浏览器中访问：`http://localhost:端口/#/tree`

## 使用方法

1. **加载数据**
   - 点击"选择文件"按钮
   - 选择 HRDS 格式的 JSON 文件（如 `E:\models\data\Section\HRDS\test\ACL_2020.acl-main.99.json`）

2. **浏览层级结构**
   - 左侧树形视图展示文档的完整层级结构
   - 点击节点前的箭头图标展开/折叠子节点
   - 点击节点本身选中并查看详情

3. **查看详情**
   - 在"分栏模式"下，右侧面板显示选中节点的详细信息
   - 包括：节点类型、父节点、关系类型、页码、位置信息等

4. **切换视图模式**（点击按钮循环切换）
   - **分栏模式**（默认）：左侧树形结构 + 右侧节点详情
   - **纸张模式**：左侧精简树形 + 右侧论文预览（还原论文排版效果）
   - **Bbox模式**：左侧精简树形 + 右侧坐标可视化（基于bbox还原元素在页面的实际位置）

5. **快捷操作**
   - "全部展开"：展开所有层级
   - "全部折叠"：折叠所有层级

## 数据格式说明

### 关键字段

- `class`：语义类别
  - `title`：标题
  - `author`：作者
  - `affili`：机构
  - `mail`：邮箱
  - `sec1/sec2/sec3`：一级/二级/三级标题
  - `para`：段落
  - `fstline`：段落首行

- `line_id`：当前节点唯一 ID

- `parent_id`：父节点 ID（-1 表示根节点）

- `relation`：节点关系类型
  - `contain`：包含关系（父子）
  - `equality`：并列关系（兄弟）
  - `connect`：连接关系（段落内多行文本）
  - `meta`：元信息

- `is_meta`：是否为元信息节点

- `page`：所在页码

- `box`：位置信息 [x1, y1, x2, y2]

## 特性

1. **智能层级构建**
   - 根据 `parent_id` 和 `relation` 自动构建树形结构
   - 支持 contain、equality、connect 等多种关系类型

2. **三模式展示**
   - 分栏模式：完整展示文档结构和节点详情
   - 纸张模式：还原论文阅读效果
   - Bbox模式：基于坐标可视化元素位置，支持分页浏览、缩放控制

3. **视觉标识**
   - 不同节点类型用不同颜色图标标识
   - 关系类型用彩色徽章区分
   - 选中节点高亮显示

4. **交互体验**
   - 点击节点查看详情
   - 支持展开/折叠操作
   - 悬停高亮效果
